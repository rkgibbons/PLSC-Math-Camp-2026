%=====================================================================

%=====================================================================
%  HOW TO SHADE A SINGLE CELL
%---------------------------------------------------------------------
%  Put \cellcolor{<color>} at the very start of the cell's content:
%
%      Normal cell & \cellcolor{yellow}Shaded cell & ... \\
%
%  Lighter tint via a mix:            \cellcolor{blue!15}
%  Named colors (dvipsnames option):  \cellcolor{LimeGreen!30}
%  Your own color, defined once in the preamble:
%      \definecolor{highlight}{HTML}{FFE08A}
%  then:                              \cellcolor{highlight}
%
%  Related:
%    \rowcolor{gray!20}     -> shades a whole row (place before its 1st cell)
%    \columncolor{gray!20}  -> shades a whole column (put inside the column spec,
%                              e.g. >{\columncolor{gray!20}}m{\colWidthOne\linewidth})
%=====================================================================
